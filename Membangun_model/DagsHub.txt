========================================
DAGSHUB INTEGRATION - Wine Classification
========================================

Repository URL:
https://dagshub.com/<USERNAME>/<REPO_NAME>

--------------------------------------------------------
CARA SETUP DAGSHUB:
--------------------------------------------------------
1. Buat repository di https://dagshub.com
2. Install dagshub: pip install dagshub
3. Set username dan repo name di modelling_tuning.py:
   DAGSHUB_USERNAME = "<USERNAME_ANDA>"
   DAGSHUB_REPO = "<REPO_NAME_ANDA>"
4. Jalankan modelling_tuning.py:
   python modelling_tuning.py
5. Semua artifact akan otomatis ter-track ke DagsHub.

--------------------------------------------------------
ARTIFACT YANG DI-TRACK:
--------------------------------------------------------
- confusion_matrix.png
- classification_report.txt
- feature_importance.png
- model_summary.txt
- training_log.txt
- roc_curve.png
- Model RandomForest (MLflow model format)
